# iOS 1.0 Decrypt from Android/Termux

Decrypt and extract the complete iOS 1.0 firmware (iPhone OS 1.0, build 1A543a, iPhone 2G / m68ap, S5L8900) entirely from an Android smartphone using Termux.

## Scripts

- `scripts/decrypt_img2.py` — decrypt IMG2 containers (S5L8900 boot chain, kernelcache)
- `scripts/unlzss.py` — decompress Apple complzss kernelcaches
